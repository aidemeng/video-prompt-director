# 交付与审查

## 先形成执行事实，再组织语言

在内部厘清以下事项，成品不必机械保留所有标题：

| 检查项 | 需要确定的事实 |
|---|---|
| 片段任务 | 本段发生的事件、观众新增的信息、结束悬念或结果 |
| 输入条件 | 片长、画幅、风格、真实参考图、音频需求、已知模型条件 |
| 入场状态 | 谁在哪里、在做什么、看哪里、持有什么、哪些前情已发生 |
| 过程 | 可观察的动作与台词，触发、接触或阻力，动作的结果 |
| 摄影 | 观众从哪一侧、何种景别看到什么；运动或切换为何必要 |
| 声音 | 谁说什么，声音从哪里来，如何与画面事件同步 |
| 出口状态 | 人、物、环境的确切变化，下一段须继承什么 |
| 边界 | 不能提前出现的剧情；本次已出现或很容易出现的生成偏差 |

不足以确定关键人物、剧情或必要参考素材时先问。

## 时间预算

- 时间段覆盖请求时长，没有无人说明的空白、重叠或越界；时间窗是执行规划，不保证模型逐帧准确。
- 对白以自然朗读估时，考虑停顿、吸气和听者反应，不只用固定字数阈值判断。
- 区分可以并行的行为（走路与说话）和必须串行的动作（接稳杯子后松手）。
- 极远景转脸部近景需要可理解的摄影方案；不要让摄影机在极短时间跨越巨大距离而仍被要求自然平稳。
- 末尾按叙事需要留下可辨认结果，但不固定每段必须留一秒、不强行定格。
- 用户要求超载时，说清哪组动作来不及，给出拆段或缩减的选择，不暗自更改主要事件。

## 最终输出形态

1. 代码块外列出需要上传的实际参考图及顺序。缺失或不支持的资源另行说明，不能把它写成已经存在。
2. 每个生成片段一个完整代码块，先写生成条件、参考职责和全片统一设置，再按实际镜头逐一展开下面的四部分。不要将多个镜头的构图、摄影或表演全部汇总成全片的一套四部分。
3. 一个片段中多镜头仍在一个块里；多生成片段各自独立完整。重复必要身份和环境不是冗余，用户不应自行组合。
4. 对简单改动也提供完整替换稿，除非用户明确只要改动部分。不要把解释、待选方案或多个“或”混进最终执行块。

### 每个镜头的四部分

镜头标题写编号、起止时间和事件名称；同一镜头可以含多个细分动作节点，不能因为时间窗结束就虚构一次切镜。

```text
镜头一｜0—2.8秒｜事件名称
【主体及环境】
本镜人物、场景、关键道具与入场状态。
【构图与摄影】
本镜景别、人物位置与视线、机位高度及方向、焦段、光圈与景深、对焦对象、运镜起止。
【表演与声画】
按本片段时间顺序组织声画：文戏细分表演转折，快打按连续交锋展开；同步写动作、表情、准确台词、呼吸、音效和必要摄影变化。末尾交代动作出口及声桥。
【光影与质感】
本镜光源与人物的关系、材质，以及动作引起的光影变化。

镜头二｜2.8秒起｜下一事件名称
继续分别写上述四部分。
```

- 时长、画幅、参考职责、帧率和快门等统一参数在代码块开头写一次即可。每镜仍需说明自己的构图、机位、焦点、运镜及光影；保持不变的参数可明确继承本代码块内的统一设置。不同生成片段之间不能依赖“同上”。
- 摄影参数与可见效果配对；焦段、光圈、拍摄距离和所需清晰范围相容。数字表达摄影意图，不声称模型会精确模拟。不要用毫米级肌肉位移或百分比柔焦制造没有依据的精度。
- 文戏按察觉、开口、中断与表情变化等节点划分，必要时使用0.3—0.8秒等细分窗口。快打按抢攻、受压、反击等连续交锋分配时间，只对决定性接触局部细写；不为蹬地、转腰、收肘逐项计时。时间粒度由场景决定，不默认每3秒一段，也不强迫每半秒发生新动作。
- 台词与表情可按具体词语绑定，声音按接触、脚步或呼吸绑定；听者的反应也写在同一时间线上。不让用户自行对照独立的表演表、对白表和音效表。
- 声桥或停顿跨镜头时标明其起止与剩余时长，不能在切镜后重新计时。结束姿态写在最后一个动作节点内，不另拆一套零碎栏目。
- 模型名、图号、资产名可保留原始写法；没有实际绑定的英文协议字段不增加可执行性。

## 出稿检查

- **事实：** 未改剧情、人物动机或关系；最新服装要求优先于旧资料；未暗示未获确认的身份。
- **参考：** 引用全部真实且角色分工清楚；未把参考图排版当成视频内容；光线或服饰覆盖规则不矛盾。
- **动作：** 看见目标后才反应；前置动作没有省略；力或接触存在时有后果；道具不无故消失。
- **表演：** 微表情有具体部位和变化；需要终止的笑与凝视有退出条件；没有末句又补回“余韵”等抽象要求。
- **镜头：** 景别看得见目标细节；方向衔接成立；切镜带来新信息或必要视角；声音和动作不因切镜重置。
- **时间：** 所有动作放得下；台词可自然说完；不是为了填时长添加无关事件。
- **交付：** 每段完整可复制；缺项不装作已具备；没有把指定模型未确认的能力当保证。
- **结构：** 每个实际镜头均有四部分；「表演与声画」名称正确；摄影说明没有被全片汇总替代；细分节点中的台词、表情、声音能一一对应。
- **动作粒度：** 快打以攻防关系和结果组织，不是关节步骤清单；对手持续参与，接触有反馈，收势能接下一招。文戏仍保留必要的细腻表演。
