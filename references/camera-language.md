# 视听语言与镜头调度

## 先明确五个不同维度

- **景别：** 主体在画面中多大，决定观众能看清什么。
- **焦段／视角：** 决定取景范围；和摄影机距离一起影响透视观感。不能仅写焦段就假定模型精确模拟光学。
- **机位：** 摄影机的高度、方位、与主体的距离。
- **运镜：** 摄影机怎样移动，以及为何移动。
- **剪辑与焦点：** 何时更换观察位置，何时在同画面转移注意力。

特写不等于长焦，广角不等于全景，推进也不等于变焦。技术参数有用时可以给，同时写出期望的画面关系，避免参数与可见结果相反。

## 选择表

| 方法 | 适用目的 | 写清楚什么 | 常见问题 |
|---|---|---|---|
| 极远景／大全景 | 建立地形、阵营位置、人物与巨大物体的比例 | 主体在哪里、规模参照是什么、威胁来自哪里 | 同时要求看见嘴角或手指细节 |
| 全景／中全景 | 完整动作、重心、错身、闪避 | 头脚是否完整、移动通道、结束位置 | 裁掉关键脚步却要求观众理解受力 |
| 双人中景 | 互动和即时反应、关系距离 | 双方位置、视线、谁说话谁听 | 不必要地拆成碎片化正反打 |
| 近景 | 明确表情、口型、身体局部反应 | 具体变化、触发和恢复状态 | 只有形容词，没有可见变化 |
| 特写 | 一个线索、接触点或关键微表情 | 哪个局部、为什么此时必须看清 | 与叙事无关的面部展示或道具插镜 |
| 广角／超广角 | 强化近远距离、空间纵深、主体与环境关系 | 前中后景、主体距镜头远近、哪些部位需避免边缘变形 | 将广角误作宏大的充分条件，过近拍脸 |
| 较长焦视角 | 从远处观察、弱化背景干扰、呈现层叠关系 | 观察距离和背景层次 | 仍要求夸张近大远小的透视 |
| 低机位仰拍 | 看清高处威胁、人物与上方空间关系 | 前景参照和目标位置 | 所有镜头都仰拍，空间失去方向 |
| 高机位俯拍 | 交代路线、包围、落差、行动结果 | 人物在地形中的位置 | 破坏原本需要的贴身临场感 |

“史诗、压迫、温柔”等可作为美术意图，但需落实：例如巨大阵面超出画框，远处山峰提供尺度参照；不默认天黑，不通过加怪物或新增伤亡扩写故事。

## 运镜由任务触发

| 运镜 | 合理触发 | 起止说明 |
|---|---|---|
| 固定 | 主体动作和表演已经足够，空间关系需要清楚 | 摄影机保持位置，主体自行进入或离开 |
| 推近 | 观众需要从现场转向某次决定或细节 | 从什么景别推进，到何处停止，变化在何时发生 |
| 拉远 | 显露刚才未见的威胁、规模、关系 | 保持主体可定位，说明新增可见内容 |
| 横移／跟拍 | 人物移动或需要显露遮挡后的空间 | 同向跟随谁、是否同速、何时停止跟随 |
| 摇摄／俯仰 | 随视线或攻击指向寻找目标 | 从谁或什么摇向哪个已知位置 |
| 环绕 | 需要揭示背面、包围关系或动作转向 | 围绕对象、运动范围、是否改变轴线以及如何交代 |
| 焦点转移 | 同一画面内将注意力交给另一个对象 | 从近处谁转到远处谁，另一方如何持续行动 |

不要同时写“固定机位”和“持续环绕”。需要震动时绑定实际冲击，不把全程乱晃当成动感。复杂运动确实服务剧情时可以使用，不以生成难度为由一律禁止。

## 切镜判定

先回答：不切会漏掉什么，切后观众新增什么？常见成立理由：

- 动作范围超出当前景别，需要看清完整结果。
- 人物看向某处，下一镜交代所见对象。
- 对方的反应成为当前叙事重点。
- 某个小道具或接触细节决定行动，而原镜头看不清。
- 揭示此前刻意隐藏的空间、身份或信息，且获剧情授权。

不规定每几秒切镜。一次关键动作可连续拍完，也可在明确阶段切换，但不能重复执行同一动作、遗漏接触点或改变动作方向。长镜头不是默认更高级，多镜头也不是默认更专业。

## 方向与连续性

1. 先建立角色和地标，例如女主在画面左、摊位在右、河道在摄影机这一侧；不能只写“保持同侧”而没有参照。
2. 对话可用两人连线建立轴线；动作场面还要核对移动方向和攻击来源。
3. 人物转身不等于摄影机跨轴。若需要越轴，用连续运动或能交代位置的镜头建立新方向，而不是把“禁止越轴”当所有作品的绝对审美规则。
4. 眼神方向与视线对象的位置吻合；背影、侧面、正面切换不能改变谁在看谁。
5. 非刻意跳时的镜头转换，手势、道具接触、光线、伤损与环境动作仍连续。

## 尺度与可生成性

大场景需要可比较的大小、距离、遮挡和环境响应，不只是“8K、震撼、史诗”。例如前景小树、中央人物、远山、超过山峰的阵面形成多个尺度层次。动作场面先明确目的和影响，不用无关爆炸填空。

同一短片要求跨度极大的景别时，选择有依据的切镜，或调整运动距离；不要把不可能的长距离推进包装成“一镜到底、平稳自然”。需要额外机位参考或关键帧时说明用途，不假装已有资产。
