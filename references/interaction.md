# 人物互动与具象表演

覆盖双人及必要的多人互动。初遇、告别、争执、试探是情境，不单独规定固定镜头套路。

## 视线是行动的一部分

明确关键阶段人物关注什么：事件前的目标、察觉的触发、转向对象、停留与移开。不要要求每个瞬间标注视线，但必须补足会改变剧情解读的节点。

例如偶遇：路过时看行进路线；对方进入路径后才看向其脸。若从出场就盯住对方，会改变为有意接近。分开后回望是一种动作，不需要额外指定“眼里藏着秘密”。

## 微表情的执行结构

根据需要选用：**触发 → 部位 → 变化方向和幅度 → 持续/转变 → 恢复或出口状态**。

| 抽象意图 | 可执行表演示例 |
|---|---|
| 笑意余韵 | 说话时嘴角抬起；说完嘴角放松，唇线回到自然位置 |
| 压住怒意 | 听见某句话后下颌收紧，嘴唇抿住；停一拍后开口，音量不提高 |
| 迟疑 | 手伸到杯旁停住，视线移向对方；对方点头后才握杯 |
| 发现不对 | 视线停在门锁，眉头轻收，准备迈出的脚落回原处 |
| 想挽留却没开口 | 对方转身后嘴唇微张，手抬起一小段；对方走远，手放下，嘴唇合拢 |

这些是可选翻译示例，不是各类情绪的唯一表演。不能擅自用它们给角色添加用户未要求的感情或动机。

精细表演可以同时涉及眼神、嘴部和呼吸，前提是互相协调且画面看得见。不要用“一个动作”原则禁止合理的复合表演；也不要让所有面部部位在同一时刻都变化。用先后和重点组织细节。

“自然”不是动作说明。“自然微笑”仍需要场景触发；若笑是否结束影响人物解读，要明确结束。删掉抽象词后，检查是否又在末尾补回“温柔而失落的余韵”等要求。

## 对白与听者

- 同期对白标明说话人、准确原句、语速/音量中真正有用的差异，拍摄角度要支持所需口型。
- 明确谁在听、收到哪句信息后反应；不要求听者始终盯脸，也不把听者做成静止背景。
- 无声点头和有声回答不同，不自动补“谢谢”“嗯”等词。
- 画外音不要求可见人物同步口型；原生音频未确认时，不能承诺一次生成完整口型成片。
- 多人对话优先厘清轮次和主要反应者；背景人物不抢戏，但并非全员冻结。

## 移动、错身与接触

- 路线用共同地标或统一画面方向描述。同向让路写“两人都向河栏方向侧移”，而非“各自向右”。
- 近身互动说明实际间隙或接触部位；没有碰撞的场景不加撞击反应。
- 需要表现停步、卸力、滑退时，画面应包含对应身体部位，不能以面部特写替代全身结果。
- 跟随、目送、回望是不同关系：持续看着对方离开不等于先走开再回头；动作差异会改变动机解读。
- 角色交错后重新核对屏幕位置，不能因为切近景把双方放回原位。

## 道具交接

用可执行的所有权变化组织动作：

1. 谁拿着、哪只手、接触哪一部分，道具的起始状态。
2. 谁先伸手、接触何处，原持有者何时仍未松手。
3. 接稳后另一方松手，之后道具随谁移动。
4. 结束时的位置、水量/开合/破损等是否变化，下一段从哪里接。

杯、信封、武器各有不同接触要求；只补本场景必要细节。没有参考道具时可在用户授权范围内给普通外观，不能引用不存在的道具板。
