# 完整示例：桥边初遇

本例展示逐镜头四部分与声画同步写法。假设已上传男女主造型图，并确认15秒及原生音频能力。实际任务以真实输入为准。
上传说明：图一男主，图二女主；本例无场景图。

```text
生成15秒、16:9横屏写实3D古风短剧。图一限定男主身份与服装，图二限定女主身份与服装；不继承造型图站姿、背景或多视图排版。
统一摄影基准：24fps、1/48秒快门观感，正常速度，日光白平衡，自然肤色。中文同期对白，无字幕、旁白或配乐。
两位陌生人在桥边同向让路一次，女主说“你先”，男主点头经过；女主继续走后回望。不交换姓名，不接触，不跟随，不施法。

镜头一｜0—10秒｜碰面与错身
【主体及环境】
晴天古城石桥入口。画面左侧河道与石栏，右侧木摊，中间通道足够错身。男主在右侧刚询问完摊主，手持折好的米白纸画像；女主从左向右走，看自己的前路。摊主不说话，远处行人不遮挡主体。
【构图与摄影】
摄影机位于临河一侧，平视双人全景，35mm等效视角、f/5.6景深观感，双方脚步与面部朝向可辨认。焦点覆盖互动区域，背景适度柔化。开头固定，错身时小幅横移跟随男主；不跨到摊位一侧。前10秒连续拍摄，内部时间节点不切镜。
【表演与声画】
0—0.8秒：男主把画像完整收进衣襟，纸张摩擦声清楚；女主继续看前路，尚未看他。
0.8—1.5秒：男主放下手，转身迈入通道。女主看见有人进入路径，视线移向他的脸，步幅缩短。
1.5—2.2秒：男主也看见女主，两人停步，相距约半米，没有撞上。停步声清楚，河水与街声不断。
2.2—3.0秒：两人同时朝临河一侧侧移小半步，再次挡住彼此，停下脚步。只发生一次同向让路。
3.0—3.5秒：女主看一眼被挡住的通道，嘴角轻轻抬起，视线回到男主脸上。
3.5—4.2秒：女主以正常成年声线说“你先”，口型同步；同时向摊位方向退开半步，让出通道。说完嘴角放松，不维持微笑。
4.2—4.7秒：女主退稳，男主看清通道后轻点头一次，不出声。
4.7—6.2秒：男主从女主临河一侧通过，肩部保持间隙，视线转向前路。摄影机小幅向左跟随，仍保留右侧女主。衣料与脚步声连续。
6.2—7.0秒：男主继续向左走；女主不跟着他转头，视线回到右侧前路。
7.0—9.0秒：女主向右走两步，嘴角保持平常位置。两人脚步向不同方向离开，画像留在男主衣襟内。
9.0—10.0秒：女主减速停步，尚未回头；男主继续走远。她停步声结束，河水和男主渐远脚步延续进入下一镜。
【光影与质感】
日光从石桥上游方向照来，河面反光照亮暗侧。衣料有织纹，石板有磨损，肤色自然。跟拍中光源保持场景内位置，不为每个人切换主光。

镜头二｜10—15秒｜回望与离开
【主体及环境】
承接女主停步状态，双脚仍朝右侧；男主在左侧远处继续走，画像仍由男主保管。
【构图与摄影】
仍从临河一侧拍摄，平视女主腰部以上侧面中景，50mm等效视角、f/4景深观感。对焦女主面部，左侧远处保留男主虚焦背影。固定机位，切镜用于看清回头，不改变人物位置。
【表演与声画】
10.0—10.6秒：女主停稳后转头向左看男主，肩膀略随头转，双脚不转。承接河水和男主脚步，不重复女主停步声。
10.6—11.6秒：视线停在男主背影，嘴唇自然闭合、嘴角放松，不额外挑眉或微笑。男主不回头，脚步继续变远。
11.6—12.2秒：女主转回右侧，视线回到前路，肩膀恢复朝向。
12.2—15.0秒：女主重新迈步向右离开画面，脚步从近处响起并逐渐减弱。摄影机不追随，不加心跳或神秘音效，环境声持续到结束。
【光影与质感】
沿用上游日光与河面反光，转头时脸部明暗随朝向变化。保留发丝与皮肤细节；观察角度变化后背景自然改变，不要求散景形状与上一镜相同。
```

## 示例边界

- 两个实际镜头各有四部分；镜头内部细分节点不是新的镜头。
- 表演、台词、音效和摄影变化绑定同一时间线，不分成待拼接的清单。
- 转折处细分时间，持续行走允许较长窗口；不为每个节点增加停顿。
- 15秒、摄影参数、无配乐及一次切镜只是本例选择，不是通用限制。
